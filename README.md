
# 🎯 Plinko Game (p5.js + Matter.js)

A browser-based Plinko game built using **p5.js** for rendering and **Matter.js** for physics simulation. Drop particles and watch them bounce through pegs to random slots — just like the classic Plinko!

---

## 🚀 Features

- Real-time physics simulation
- Interactive particle drops
- Smooth animations using p5.js
- Collision handling with Matter.js
- Simple and clean UI

---

## 📂 Project Structure


Plinko-game/
│── index.html # Main entry point
│── sketch.js # Core game logic
│── /js # Game objects (Particle, Plinko, etc.)
│── /libraries # p5.js and Matter.js libraries

### ✅ Method 1: Open Directly

1. Download or clone the repository
2. Extract the files (if zipped)
